# Credit Risk Scorecard Platform

## Overview

An end-to-end Credit Risk Scorecard Platform demonstrating the complete
machine learning lifecycle, from data engineering and feature
engineering to model deployment and an AI-powered assistant.

## Features

-   Production-grade preprocessing pipeline
-   Weight of Evidence (WoE)
-   Information Value (IV)
-   Logistic Regression scorecard
-   XGBoost, Random Forest and Neural Network benchmarks
-   Streamlit application
-   LangChain + Ollama AI Assistant

## Project Workflow

Raw Data -\> Data Engineering -\> EDA -\> Preprocessing -\> WoE/IV -\>
Feature Selection -\> Model Development -\> Benchmarking -\> Scorecard
-\> Streamlit -\> AI Assistant

## Technology Stack

-   Python
-   Pandas
-   NumPy
-   Scikit-learn
-   XGBoost
-   TensorFlow/Keras
-   Streamlit
-   LangChain
-   Ollama
-   Llama 3
